# DOM snapshots

Generated by `tools/test-dom.mjs` — **do not edit by hand.**

These are the surfaces `bes.js` builds at runtime: the toast, the open combobox and its
zero-results state, the date grid, a closed modal, PIN entry, a sorted table, a chart with
its table equivalent, and tabs in both directions. None of them exists in any hand-written
HTML file, so before these snapshots existed no static gate had ever scored them — which is
how a 1.00:1 toast shipped in v1.0.1.

`tools/audit-contrast.py` walks this directory alongside `pages/` and `components/`.
Regenerate with `node tools/test-dom.mjs`; CI fails if the committed output has drifted.
